
# Terai Flood Alert System

A simple AWS serverless project for monitoring river water levels in Nepal's Terai region.

If the water level becomes dangerous, the system automatically sends an SMS alert.

## Services Used

- AWS Lambda
- Amazon DynamoDB
- Amazon SNS
- Amazon API Gateway
